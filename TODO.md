## 2. Стили анимации текста — по словам, но с другими анимациями

Не «Караоке / По строкам», а пословные стили со своим характером (все экономные: без эффектов на каждое слово, пружины только у видимых строк):
- «Прыжок» — слово подпрыгивает и чуть увеличивается, когда звучит;
- «Волна» — по звучащему слову бежит волна по буквам;
- «Проявление» — слова всплывают снизу и проявляются из прозрачности;
- «Неон» — заливка + мягкое свечение одним общим слоем на строку, а не тенью на каждое слово.

## 3. Правильный WASAPI

Сейчас вывод — DirectSound (1.9.6): частоту пересчитывает Windows, libVLC не ресемплит. Цель — снова WASAPI (mmdevice), но без проблем:
- взять `libsoxr_plugin.dll` (и при необходимости `libsamplerate_plugin.dll`) из официальной сборки VLC 3.0.x для Windows x64 и класть в `libvlc/win-x64/plugins/audio_filter` при сборке (build.ps1 / csproj), проверить, что наш libVLC его грузит (совпадение версии ядра);
- прогнать замер: 7 перемоток (было: speex — 2950 сбоев и 99 % ядра, DirectSound — 2 и 2 %) и THD+N синуса 1 кГц / 15 кГц 44,1 → 48 кГц;
