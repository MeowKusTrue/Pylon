<h1 align="center">Pylon</h1>

<p align="center">Современный открытый медиаплеер для Windows на движке VLC (libVLC): переосмысленный интерфейс VLC,
синхронизированные тексты песен, эквалайзер и эффекты, конвертер и трансляция на телевизор.</p>

Pylon воплощает в настоящий плеер открытый редизайн **«VLC Redesign»** от **[Juxtopposed](https://www.youtube.com/@juxtopposed)**. Внутри у него libVLC 3, поэтому он играет всё, что играет VLC: почти любые аудио- и видеоформаты, диски и сетевые потоки.

## Возможности

- **Плеер:** видео в скруглённой рамке, музыкальный режим с размытой обложкой, шкала-волна с превью кадров, полноэкранный режим с плавающей панелью, режим «скрыть интерфейс» и мини-плеер.
- **Библиотека:** главная («Продолжить просмотр», «Слушать снова»), папки с видео и музыкой, альбомы, исполнители и жанры по тегам, плейлисты с обложками, история и очередь.
- **Сеть:** сетевые потоки, устройства в локальной сети (UPnP / mDNS), подкасты (RSS) и интернет-радио из каталога radio-browser.info.
- **Настройки:** 13 разделов и около 150 параметров. Они применяются сразу; если нужно перезапустить libVLC, воспроизведение продолжается с того же места.
- **Эффекты:** 10-полосный эквалайзер с пресетами, компрессор, пространственный звук, расширение стерео, сдвиг тона, караоке. Для видео: цвет, обрезка, поворот.
- **Темы:** тёмная, светлая, как в Windows, OLED чёрная, «Полночь», Nord и сепия, плюс 9 акцентных цветов и настраиваемое скругление углов (на Windows 11 — и у самого окна).
- **Тексты песен:** караоке по слогам в стиле Spicy Lyrics (свечение, размытие дальних строк, клик по строке — перемотка). Читает `.ttml` (Apple / Spicy Lyrics / spicy-translate, с бэк-вокалом и дуэтами) и `.lrc` рядом с треком или находит синхронизированный текст на LRCLIB.
- **Видео:** NVIDIA RTX / Intel Super Resolution и RTX Video HDR, главы на шкале, закладки (`Ctrl+B`), 360°-видео с обзором мышью, размытый фон из кадров самого видео вместо чёрных полос.
- **Windows:** медиапанель (трек и обложка в плашке громкости и на экране блокировки, медиаклавиши), кнопки в превью на панели задач, свои иконки для видео- и аудиофайлов.
- **Сайты:** YouTube, Twitch, VK, Rutube, SoundCloud и ещё около 1800 сайтов через [yt-dlp](https://github.com/yt-dlp/yt-dlp) (скачивается при первом использовании и обновляется сам). Плейлист или канал попадает в очередь целиком.
- **Плавный переход:** песни перетекают одна в другую (Настройки → Воспроизведение → Плавный переход между песнями).
- **Пульт с телефона:** QR-код — и браузер телефона управляет воспроизведением («⋯» → «Пульт с телефона»).
- **Spotify:** импорт плейлистов по ссылке (сначала ваши файлы, остальное с YouTube) и текст в стиле Spicy Lyrics для того, что играет в приложении Spotify.
- **Связь с сервисами:** скробблинг в Last.fm, статус в Discord, субтитры из OpenSubtitles, узнавание песни по звуку (AcoustID), совместный просмотр.
- **Инструменты:** петля A-B (`Shift+L`, отрезок виден на шкале), таймер сна с плавным затуханием, настоящая волна трека на шкале музыки (считается один раз в фоне и кэшируется).
- **Анимации:** быстрые плавные появления панелей, меню, окон и страниц библиотеки. Действия с клавиатуры остаются мгновенными, а переключатель «Эффекты анимации» в Windows их отключает.
- **Спектр аудио:** живые полосы под обложкой, по желанию и поверх видео. Захватывается только звук самого Pylon (WASAPI process loopback, Windows 10 2004+).
- **Языки:** русский и английский (Настройки → Общие → Язык интерфейса).
- **Обновления:** при запуске проверяет релизы на GitHub и обновляется сам, скачивая только изменившееся (дельта-обновления). После обновления показывает, что нового.
- **Управление:** переназначаемые горячие клавиши (в том числе глобальные), действия колеса и щелчков мыши, свой набор кнопок на панели.
- **Ещё:** запись (`Shift+R`), снимки (`Shift+S`), Chromecast, подбор субтитров ко всему сезону, профили, одно окно на всё.
- **Интеграция с Windows:** установщик регистрирует аудио- и видеоформаты, у каждого своя иконка, и добавляет «Воспроизвести в Pylon» в меню папок.

## Установка

Скачайте со страницы [Releases](../../releases):

- `Pylon-win-Setup.exe` — установщик. Ставится для текущего пользователя в `%LocalAppData%\Pylon` без прав администратора и регистрирует типы файлов.
- `Pylon-win-Portable.zip` — портативная версия: распакуйте куда угодно. Тоже обновляется сама, но типы файлов не регистрирует.

Windows не разрешает программам самим назначать себя плеером по умолчанию. Чтобы выбрать Pylon, откройте **Настройки → Библиотека → Плеер по умолчанию**.

Стоит Pylon 1.0–1.2? Обновитесь из приложения как обычно: он перейдёт на новый установщик и удалит старую копию, настройки и библиотека сохранятся.

Нужна Windows 10 или 11 (x64). .NET ставить не нужно, он уже внутри.

## Обновления

Pylon при запуске проверяет [последний релиз](../../releases/latest). Проверку можно выключить в **Настройки → Общие → Проверять обновления автоматически** или проверить вручную через **… → Проверить обновления…**.

Нажмите **Обновить**: Pylon скачает только изменившиеся файлы (обычно несколько сотен КБ), перезапустится в новой версии и покажет, что в ней нового.

## Сборка

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download). Для упаковки нужен [Velopack](https://velopack.io) (`dotnet tool install -g vpk`); [Inno Setup 6](https://jrsoftware.org/isdl.php) собирает маленький мост, который переводит установки 1.0–1.2.

```powershell
dotnet run --project Pylon          # запуск из исходников
.\build.ps1                         # dist\releases\: установщик, zip, пакеты обновлений
.\build.ps1 -Version 1.1.0
```

### Как выпустить новую версию

Релизы собирает GitHub Actions (`.github/workflows/release.yml`). Каждый пуш в `main` дополнительно проверяется сборкой (`ci.yml`).

1. Закоммитьте изменения в `main`.
2. Поставьте тег с номером версии и запушьте его:
   ```bash
   git tag v1.1.0
   git push origin v1.1.0
   ```
3. Workflow соберёт установщик, zip, полный и дельта-пакеты обновления и опубликует релиз на GitHub. Описание релиза — раздел этой версии из [CHANGELOG.md](CHANGELOG.md), так что допишите его до тега.
4. Установленные копии увидят обновление при следующем запуске или сразу через **Проверить обновления…**.

Номер версии берётся из тега, править `Pylon.csproj` не нужно.

Держите папку проекта по короткому пути, например `D:\Projects\Pylon`. libVLC 3 не загружает плагины из путей длиннее 260 символов, и пропадает звук.

Иконки — [Phosphor](https://phosphoricons.com). Чтобы добавить новую, укажите её имя в коде и запустите `python Pylon/tools/sync-icons.py <путь к @phosphor-icons/core/assets>`.

Новые тексты интерфейса пишутся в коде на английском, а перевод добавляется в `Pylon/Strings.Ru.cs`.

## Политика конфиденциальности

В Pylon нет телеметрии, аналитики, рекламы и собственных аккаунтов. Он никуда не отправляет ваши файлы, библиотеку и историю — они хранятся в `%AppData%\Pylon` на вашем компьютере. В сеть Pylon выходит только ради функций ниже и только с теми данными, которые им нужны:

- **Обновления:** GitHub (github.com, api.github.com) — проверка при запуске и загрузка новых версий. Выключается в Настройки → Общие.
- **Тексты песен** (включено по умолчанию, Настройки → Интерфейс → Текст песни): исполнитель, название, альбом и длительность трека уходят в [LRCLIB](https://lrclib.net), [ListenBrainz](https://listenbrainz.org) (чтобы найти Spotify id) и [Spicy Lyrics](https://spicylyrics.org). Только если вы добавили свои ключи приложения Spotify — ещё Spotify Web API и Deezer для того же поиска.
- **Названия и обложки** (выключено по умолчанию, Настройки → Приватность): исполнитель и альбом или название уходят в iTunes Search API за недостающими обложками, а libVLC делает собственные запросы метаданных. Песни совсем без тегов узнаются по аудиоотпечатку (а не по самому звуку) через [AcoustID](https://acoustid.org), обложки — из Cover Art Archive; утилита отпечатков fpcalc один раз скачивается с GitHub.
- **Spotify:** импорт читает публичную страницу Spotify по вставленной ссылке; песни, которых нет в библиотеке, ищутся на YouTube по исполнителю и названию. «Текст для Spotify» берёт трек из медиа-сессии Windows на этом компьютере.
- **То, что вы открываете сами:** сетевые потоки, радио (каталог [radio-browser.info](https://www.radio-browser.info)), добавленные вами подкасты и страницы сайтов через yt-dlp, который обращается к сайту этой страницы.
- **Входить на сайты с cookies из браузера** (выключено по умолчанию, Настройки → Сеть): только если вы выбрали браузер, yt-dlp читает его cookies на этом компьютере и использует их для открываемой страницы — чтобы пройти проверку «вы не бот» и возрастные ограничения. Pylon эти cookies не сохраняет, не копирует и никуда больше не отправляет.
- **Программы, которые скачиваются только после вопроса:** yt-dlp (github.com/yt-dlp), ffmpeg для склейки (github.com/BtbN/FFmpeg-Builds) и установщик превью Icaros (github.com/Xanashi/Icaros).
- **Только если вы их включили или используете:** скробблинг в Last.fm (исполнитель, название, альбом, время; вход — на сайте Last.fm, пароль Pylon не видит), поиск субтитров в OpenSubtitles (имя и хеш файла) и статус в Discord (название трека или видео передаётся приложению Discord на вашем компьютере).
- **Локальная сеть, только пока вы ими пользуетесь:** пульт с телефона, трансляция на ТВ и совместный просмотр слушают вашу локальную сеть; в их адресах случайный ключ. Поиск Chromecast в локальной сети включён по умолчанию (Настройки → Запись → Искать устройства для трансляции); поиск других устройств в сети — когда вы открываете Сеть → Локальная сеть.
