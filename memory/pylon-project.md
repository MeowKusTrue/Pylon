# Pylon — текущее состояние

- Актуально: опубликована 2.1.5 (256d566), CI и Release успешны, семь файлов релиза проверены. В рабочей копии реализованы следующие 12 улучшений и переделка левой панели: [отчёт](../docs/features-2026-11-13.md). Пользователь разрешил выпуск 2.1.6; версия и двуязычные заметки подготовлены, 142 Release Checks прошли повторно.
- Записи ниже описывают предыдущие этапы и сохраняются как история.

- 13.11.2026 подготовлены все 20 пунктов общего аудита после 2.1.4; пользователь разрешил выпуск 2.1.5. Состав и проверки: [optimization](../docs/optimization-2026-11-13.md). Проверки с отдельным PYLON_DATA, WPF в SoftwareOnly и маленькие CPU-превью; аппаратный стресс не выполнялся.
- GitHub Actions восстановлены в 090ecf1: ручные запуски CI/Release, тайм-ауты, отдельный профиль Checks, защита уже опубликованного тега. Новые CI и проверка Release прошли; старые два запуска на GitHub не отменяются (HTTP 409).

- Релизная версия 2.1.4, тег v2.1.4; предыдущая версия 2.1.3, commit 0db58e9. Пользователь разрешил выпуск накопленных исправлений и анимаций.
- Актуальные задачи: [TODO](../TODO.md). Подробные находки/проверки: [стабильность](../docs/stability-2026-11-11.md), [продолжение](../docs/followup-2026-11-11.md).
- 103 Release Checks и проверки WPF прошли. Настоящий ffmpeg проверяет нормализацию склейки, звук/тишину частей, длительность FLAC и отмену. Интеграционные пакеты 2.1.4/2.1.5 созданы только для тестового ID PylonCheck20261111; обновление, запуск, сохранность данных и удаление проверены.
- Свой движок остаётся за настройкой, выключенной по умолчанию. Звуковая кривая не повышалась; высокое усиление/HDR передаются libVLC. Основной выход — waveOut; старое решение про DirectSound в архиве TODO не актуально.
- Старые опубликованные бинарники не изолируют Autostart через PYLON_DATA: первый тест подменил Run\Pylon временным путём, он восстановлен на основную установку. В рабочем коде CanWriteShell запрещает все shell-изменения тестовым профилям/installer probe; повторный установленный тест сохранил основной автозапуск. Старые версии проверять через PYLON_VELOPACK_TEST, до теста фиксировать общий автозапуск.
- Не подтверждены исходный однократный скачок громкости и белёсый интерфейс на чужой урезанной Windows. Физические Bluetooth/USB-выходы не отключались; программная потеря выхода, фон, громкость/mute и позиция проверены отдельно.
