# Pylon brand files

PNGs are generated by `python Pylon/tools/make-brand.py` from `Pylon/Assets/Icons/logo.svg`; the SVGs are the logo in its variants.

| File | Size | Where it goes |
|---|---|---|
| `pylon.png` | 1024 × 1024 | Discord Developer Portal → Rich Presence → Art Assets, asset name **pylon**; also the app icon field on Discord |
| `play.png` | 512 × 512 | Discord Art Assets, asset name **play** (small badge while playing) |
| `pause.png` | 512 × 512 | Discord Art Assets, asset name **pause** (small badge while paused) |
| `pylon-512.png` | 512 × 512 | App logo for Last.fm, AcoustID, OpenSubtitles or anywhere else that asks |
| `social-preview.png` | 1280 × 640 | GitHub → repository Settings → Social preview; posts about Pylon |

Asset names on Discord must match exactly (`pylon`, `play`, `pause`): Pylon refers to them by these names.
