# Улучшения после проверки стабильности — 11 ноября 2026

Состав релиза 2.1.4 и выполненные до публикации проверки. Предыдущие исправления: [stability-2026-11-11.md](stability-2026-11-11.md).

## Поиск и производительность

- Локальная запись подбирается по нормализованному названию и точному имени исполнителя, а не подстроке. Разделяются исполнители через запятую/точку с запятой/feat/ft; имя группы с `&` не разрезается вслепую. Учитываются известная длительность и ISRC; без известной длительности файл не подставляется в запрос с заданной длительностью. Это сознательный выбор в пользу поиска нужной записи вместо подмены похожей.
- Индекс сбрасывается при изменении библиотеки и после чтения новых тегов. Внутри пакетного импорта добавление каждого веб-элемента больше не перестраивает индекс всех локальных файлов. Индексация заполняет длительность и перечитывает старые записи, у которых её не было.
- Список кодировщиков ffmpeg кэшируется по пути и времени изменения EXE, до четырёх вариантов. Метаданные используют один лениво создаваемый LibVLC с потокобезопасной инициализацией; Media освобождается с задержкой после callback разбора.

## Резервные копии и очередь

- До замены настроек/библиотеки сохраняется прежний корректный документ: один снимок за день и версию, три последних на каждый документ. Перед обновлением создаётся отдельный снимок. Проверяется и JSON, и структура документа.
- При ошибке запуска предлагается последняя корректная копия. Повреждённый оригинал сохраняется под уникальным именем `.unreadable-*`; восстановление выполняется через временный файл.
- Очередь, выбранный элемент и позиция сохраняются отдельно в `queue.json`. Запуск без аргументов восстанавливает очередь без автозапуска. Файл, переданный Проводником/launcher, имеет приоритет. Повреждённая очередь не блокирует запуск.
- Сохранение очереди действует начиная с этой сборки. Уже запущенная старая 2.1.3 не записывает свою очередь в файл; новая функция не извлекает её задним числом из оперативной памяти старого процесса.

## Аудиоустройства

- Используются события Windows о смене/отключении выходов с объединением повторных уведомлений. Постоянного опроса звукового движка нет.
- При недоступном выбранном устройстве новый файл не запускается на другом выходе молча. Воспроизведение останавливается, предлагаются доступные выходы; выбор пользователя сохраняет громкость и позицию.
- Если плеер скрыт или свёрнут, окно выбора не перехватывает фокус: оно ждёт следующего нажатия Play. Отложенный запрос привязан к файлу и номеру запуска, чтобы не возобновить другой трек.
- При пересоздании движка сохраняется mute, а не только положение ползунка. Проверка WPF подтверждает оба состояния.
- Программная потеря устройства проверена в WPF; физические Bluetooth/USB-устройства не отключались.

## Фоновые задачи и склейка

- Меню «Фоновые задачи…»: прогресс, причина неудачи, отмена, повтор и результат. Завершённые задачи освобождают рабочие замыкания, история ограничена; окно обновляется по событиям с ограничением частоты.
- Конвертацию можно оставить работать после закрытия её окна. Отдельная кнопка отменяет работу; закрытие приложения отменяет задачи и останавливает дочерние процессы. Повтор обрабатывает оставшиеся элементы, не конвертирует успешные повторно.
- Офлайн-загрузки также видны в списке; отмена отключает автоматическую догрузку плейлиста, повтор включает её снова. Успешные файлы остаются в библиотеке.
- Склейка проверяет кодеки, размеры, FPS, частоту и каналы звука. Несовместимые части с пресетом кодирования предварительно приводятся к общим параметрам, затем объединяются. Пропорции видео сохраняются с полями; базовые параметры берутся от первой части/первой звуковой дорожки и выбранного пресета.
- Для видео без звука при наличии звука в других частях добавляется тишина. Смесь видео и чистого аудио требует аудиопресета; отсутствующий звук нельзя объединить в аудиозапись. Это не универсальная нормализация всех повреждённых/экзотических контейнеров.
- FLAC пересобирает заголовок длительности без потерь; прямое копирование FLAC предлагает выбрать пресет FLAC. Иначе скопированный STREAMINFO оставлял длительность только первой части.

## Анимация

- У текста песни есть выход и обратимый повторный вход; уходящая панель не принимает клики. Обложка и подпись переходят к новой раскладке через render transform: ширина сетки пересчитывается один раз, а не каждый кадр.
- Мини-текст и переключение «Текст / Очередь» в пульте получили короткие переходы. Каждая читаемая строка отдельно не перезапускает анимацию панели.
- Уменьшены response существующих пружин панелей/меню/переключателей; ненужные драйверы для неизменившихся свойств не создаются. Новая библиотека анимации не добавлялась.
- Выключенные эффекты Windows и клавиатура сохраняют мгновенное переключение. Появление, выход, разворот посередине и отключённые эффекты проверены в WPF.

### Найденная проблема изоляции и повторная проверка

Первый запуск установленной фикстуры мог менять общий `Run\Pylon`: у Autostart не было проверки отдельного профиля. Во время проверки он заменил автозапуск основной установки ссылкой на временную. Запись восстановлена на основной установленный launcher с учётом включённой настройки фонового режима.

Добавлена общая граница CanWriteShell: отдельный PYLON_DATA или PYLON_VELOPACK_TEST запрещает регистрацию, удаление регистраций, автозапуск, меню Проводника, назначение по умолчанию и удаление старой Inno-копии. Проверки не вызывают опасные операции над реестром ради отрицательного теста.

Повторная фикстура обновилась 2.1.4 → 2.1.5, сохранив значения настроек, плейлист и очередь. Обычный запуск финальной установленной фикстуры завершился с кодом 0 и не изменил заранее сохранённое значение основного автозапуска. При повторном удалении значение также сохранилось. Версии 2.1.4/2.1.5 использованы только для локального теста под отдельным ID; теги/релизы не создавались.

Остались внешние проверки: белёсый интерфейс на исходной урезанной Windows, разовый акустический скачок, реальные переключения физического аудиовыхода и пользовательские примеры нераспознанных треков. Диагностика не равна воспроизведению этих проблем.

Основания для платформенной интеграции: [Microsoft MediaDevice](https://learn.microsoft.com/en-us/uwp/api/windows.media.devices.mediadevice), [Velopack Setup CLI](https://docs.velopack.io/reference/cli/content/setup-windows), [Windows packaging](https://docs.velopack.io/packaging/operating-systems/windows).
